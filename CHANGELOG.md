## [0.1.0] - 2026-08-06

### Added

- Native two-part intake/compiler kits for Claude Code, Cursor, Codex, and Qwen Code.
- New-project and audit/revamp interview paths.
- Three content-bound approval gates with externally carried receipts.
- Separate stage-bound, best-effort single-delivery manual-handoff payloads for high-impact actions; v0.1.0 never agent-executes them, does not claim a protected replay ledger, and PLAN approval never grants blanket authority.
- Project-specific explorer, builder, verifier, critic, integrator, and coordinator contracts.
- Breaking Tempered Loop wire protocol v2, with legacy names and receipts rejected instead of aliased.
- Immutable setup and plan records, exact control-bundle binding, and artifact snapshot plus Git identity binding.
- Deterministic nonce/hash/path/snapshot/temp-stage helpers bundled identically for every host, with root binding, isolated absolute-interpreter rules, setup/bundle verification, and stage-bound ACTION handoff consumption.
- Portable path containment, symlink/junction and collision rejection, depth-one delegation, and exclusive non-file resource ledgers.
- Exact helper-digest bootstrap before cross-session project-authority reads, plus wrapper-bound payload hashing and strict receipt grammar.
- Fail-closed partial-materialization quarantine and terminal receipt emission; no compiler mutates state after issuing a receipt.
- Explicit artifact byte/mode snapshots, separate Git commit identity, and advisory-only dirty-worktree review without false cryptographic claims.
- Explicit trusted-repository and clean-bootstrap threat modes; remote/cloud execution is unsupported in this public preview.
- Finite critique budgets, plateau stopping, rollback, and human-decision terminals.
- Child-simple and detailed platform setup guides.
- Dependency-free semantic/adversarial validation and a pinned GitHub Actions workflow for Windows, macOS, and Ubuntu.
- Public attribution, security, contribution, and licensing documentation.

### Validation

- Static encoding, link, frontmatter, exact protocol grammar, receipt-chain, circularity, path, helper-consistency, adversarial fixture, archive, and public-release audits.
- Live comparative quality benchmarks and complete happy-path smoke tests on all four hosts remain future work; this release is a prerelease public preview.
